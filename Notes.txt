Dynamic entity will have their position (both x and y), rotation (z),
flip bit, and animation rect updated every frame.

The color, center (pivot point), and scale will only be updated once before running the render loop.

Static entity will only have the animation rect updated every frame

The position (both x and y), rotation (z), flip bit, color, and scale will only
be updated once before running the render loop.

A example of a static entity is a tree sprite swaying in loop (by updating animation).
The position, rotation, etc... does not need to be updated.
